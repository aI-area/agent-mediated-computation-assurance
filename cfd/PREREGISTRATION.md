# V19 CFD case — prospective claim and acceptance rules

Freeze this file before any solver run: record its SHA-256 in `logs/preregistration.sha256`, together with the date and both authors' initials. Any change made after a run starts creates a new claim version, as Section 5 of the paper requires.

## Claim c_1
"With OpenFOAM v2312 simpleFoam and k–ω SST, the steady 2-D incompressible NACA 0012 flow at Re = 6×10⁶ and α ∈ {0°, 2.15°, 10°, 15°} has the following properties for C_L and C_D on the finest grid (1793×513):
(i) iterative and discretization errors are bounded as stated in rule N;
(ii) the results agree with the NASA TMR SST code-to-code values within the stated tolerance (code-to-code check, under N);
(iii) the results agree with the Ladson tripped data within the V&V 20 validation uncertainty (rule V)."

C_L at α = 0° is excluded as a quantity of interest because it is zero by symmetry. It is reported only as a symmetry check: |C_L| < 1×10⁻⁴.

Required set: R(c_1) = {S, A, N, V, B}.

## Amendment before freezing (2026-11-03, before any run)
- **α = 2.15° added.** This is the angle of the V18 exhibit run and of a Ladson 120-grit row. TMR code-to-code values do not exist at this angle, so the code-to-code check is not applied there.
- **Ladson reference D.** Use the 120-grit tripped set from the TMR file `CLCD_Ladson_expdata.dat` (sha256 `78cd2f6a…ed23357`).
  - At α = 0, average the two rows at ±0.01°.
  - Otherwise, interpolate linearly in α between the bracketing 120-grit points.
- **Ladson uncertainty u_D.** Take the larger of:
  - the half-range across the 80, 120 and 180-grit sets, each interpolated to α; or
  - a floor of 1% of |C_L| (minimum 0.002) or 3% of C_D.
  - The floor is a prospective allowance for wind-tunnel and trip effects, since TM-4074 gives no uncertainty.
  - Values are generated by `tools/build_reference_values.py` into `reference_values.csv`.

## S — specification fidelity
Each case must match the parameters in `tools/setup_cases.py`: grid SHA-256 from the NASA archive, ν = 1/6×10⁶, U∞ = 1, α, k∞ and ω∞ (from Tu = 0.052% and ν_t/ν = 0.009), and the schemes in `case_template`.
- S = REFUTED for that case on any mismatch.
- Also check y⁺_max < 1 on the airfoil for the two finest grids. If this fails, the wall treatment does not match the approved model, and S = UNRESOLVED.

## A — effect authorization
Only the authors launch runs, using `Allrun.sh`. Record the command, host and user in `logs/`. No agent has write access in this demonstration, so A rests on the run log and the frozen scripts.

## N — numerical verification
1. **Iterative error.** Take the last 2,000 iterations. Let e_it be the peak-to-peak value divided by 2. Require e_it ≤ 0.1 × U_num,disc for the same QoI and grid, or e_it/|Q| ≤ 1×10⁻⁵ when the discretization uncertainty is smaller. If neither holds, N = UNRESOLVED for that QoI. Residual histories are reported but are not used as a gate.
2. **Discretization error.** Use grids 449×129, 897×257 and 1793×513 (r = 2) and the Celik et al. (2008) procedure: observed order p, apparent convergence ratio R, and GCI_fine with F_s = 1.25.
   - Monotone convergence (0 < R < 1) is required. Oscillatory or divergent behaviour gives N = UNRESOLVED.
   - If p falls outside [0.5, 3], use F_s = 3 and min(p, 2), and flag the result.
   - The 225×65 grid is reported only as an asymptotic-range check.
3. **Claim thresholds.** GCI_fine(C_L) ≤ 1%. GCI_fine(C_D) ≤ 3%.
4. **Code-to-code check.** Let m be the mean of the CFL3D, FUN3D and NTS values and s their half-range. Require |Q_fine − m| ≤ max(2s, U_num) + 1% of m.
   - A larger discrepancy, with items 1–2 passing, gives N = REFUTED for the claim "agrees with TMR SST".
   - This is still not a validation result.

## V — physical validation (ASME V&V 20)
Compute E = S − D, where S is the fine-grid value and D is the Ladson value. Compute u_val = √(U_num² + u_D²), where U_num = GCI_fine/F_s × |S|; input uncertainty is neglected and this choice is stated.
- If |E| ≤ 2 u_val: V = SUPPORTED. Model error is not distinguishable from the validation uncertainty.
- If |E| > 2 u_val: V = REFUTED for the agreement proposition at that α. This is the expected outcome near stall at 15° and is reported, not hidden.
- If Ladson values or u_D are missing, or if N is not SUPPORTED: V = UNRESOLVED.
- Ladson values and u_D must be entered in `reference_values.csv` before any result is opened.

## B — evidence binding
`analyse_runs.py` records the SHA-256 of every coefficient file, solverInfo file, log, polyMesh/owner file and of this file. Every disposition refers to these hashes. A result file without a matching hash cannot be used.

## Evidence-transfer exhibit (unchanged V18 evidence)
The V18 A025 run used the unresolved Gmsh mesh: no boundary-layer cells and a domain of ±5c. It completed with quiet forces, C_L = 0.211 and C_D = 0.00501 at α ≈ 2.15°. It is kept as the ETF exhibit. Execution completed and forces were locally steady, and S is supported because the executed case matches its declared configuration. However, N is unresolved: there is no refinement evidence, and y⁺ is about 10³ against a low-Re wall model. C_D is far below the tripped-airfoil level.
